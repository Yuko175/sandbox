# 方式設計書

## 全体方式

- FastAPIでOrder Serviceを提供する。
- 注文はSQLiteに保存し、配送ステータスは保持しない。
- Service層がRepositoryから注文を取得し、外部配送APIを注文単位で呼び出してレスポンスを組み立てる。
- 外部配送システムはOrder Serviceとは別の外部環境として扱う。

## 外部API

外部APIに一括取得APIはない。配送ステータスは注文単位のHTTP要求で取得する。

外部APIの仕様は次のとおりである。

| 項目                  |     条件 |
| --------------------- | -------: |
| 1リクエストの処理時間 |    約1秒 |
| 最大同時実行数        |       10 |
| 上限超過時            | HTTP 429 |
