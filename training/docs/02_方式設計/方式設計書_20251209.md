# 方式設計書

## 全体方式

- FastAPIでOrder Serviceを提供する。
- 注文はSQLiteに保存し、配送ステータスは保持しない。
- Service層がRepositoryから注文を取得し、外部配送APIを注文単位で呼び出してレスポンスを組み立てる。
- 外部配送システムAPIは外部ベンダーのAPIである。そのため外部結合テストまでは外部配送システムのモックを使用する。

## 外部API連携

配送ステータスは注文単位のHTTP要求で取得する。

外部配送システムAPIの詳細仕様は、[外部API仕様書（配送ステータス）](./外部API仕様書_配送ステータス_20251209.md)を参照する。
