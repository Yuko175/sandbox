# 外部API仕様書（配送ステータス）

## API概要

外部配送システムには、注文単位で配送ステータスを取得するAPIがある。

複数注文を一括取得するAPIは存在しない。

## エンドポイント

- メソッド: `GET`
- パス: `/delivery-status/{order_id}`
- パスパラメータ: `order_id`（注文識別子）

## レスポンス

正常時は次のオブジェクトを返す。

```json
{ "order_id": 1001, "status": "delivered" }
```

## 処理時間・同時実行数

| 項目                  |     条件 |
| --------------------- | -------: |
| 1リクエストの処理時間 |    約1秒 |
| 最大同時実行数        |       10 |
| 上限超過時            | HTTP 429 |

## クライアント要件

- タイムアウトを設定する。
- HTTPエラーを検出する。
- 外部APIのエラーやタイムアウトを成功レスポンスに変換しない。
