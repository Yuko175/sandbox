# 機能設計書（単数取得）

## API仕様

`GET /orders/{order_id}` は指定した注文を1件返す。

レスポンスは次の項目を持つオブジェクトである。

| 項目             | 型      | 内容                        |
| ---------------- | ------- | --------------------------- |
| `orderId`        | integer | 注文識別子                  |
| `customerName`   | string  | 顧客名                      |
| `deliveryStatus` | string  | 外部配送APIの最新ステータス |

## Service処理

1. Repositoryから指定された注文を1件取得する。
2. 注文が存在しない場合は404を返す。
3. 外部配送APIから配送ステータスを取得する。
4. 注文情報と配送ステータスをレスポンスへ変換する。
5. 外部APIの失敗は成功レスポンスに変換しない。

## 外部APIクライアント

- エンドポイントは `GET /delivery-status/{order_id}`。
- 正常時は `{ "order_id": 1001, "status": "delivered" }` を返す。
- タイムアウトを設定し、HTTPエラーを検出する。

## エラー処理

- 指定した注文が存在しない場合はHTTP 404を返す。
- 外部APIのHTTPエラーやタイムアウトは検出し、成功レスポンスに変換しない。
