# 概要

Markdown形式のテキストをExcel形式に変換するためのコードです。

## 前提条件

Excelの列幅は、一律2.5ピクセルであると仮定しています。

### 変換ルール

見出しタグ（h1, h2, h3, ...）は、見出しレベルに応じて列を右にずらして記載する。
例: h1はB列、h2はC列、h3はD列... のように続く。
各見出しに続く本文は、見出しの列から1列右のセル、見出しの行から1行下のセルに記載する。
本文を記載したら、その次の行は空行にする。
Markdown内で改行があった場合は、Excelの行を一行下にずらす。

1つ目の[h1]の場合、文頭に1.をつける。
2つ目以降の[h1]の場合、文頭に2.、3.、... とつける。
[h2]の場合、直前にある[h1]の番号に続けて、文頭に1.1.、1.2.、... とつける。
[h3]の場合、直前にある[h2]の番号に続けて、文頭に1.1.1.、1.1.2.、... とつける。
